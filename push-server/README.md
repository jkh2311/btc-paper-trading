# BTCUSDT 원격 LONG/SHORT 푸시 서버 (선택 설치)

GitHub Pages는 신호를 24시간 감시하거나 잠금 화면 푸시를 **보낼 수 없습니다**.
본 디렉터리는 별도 **항상 켜진 Node.js 서버**에 배포하는 구성입니다.
실제 서버 배포·계정 설정이 없으면 원격 알림은 작동하지 않습니다.

## 준비

1. 24시간 실행되는 HTTPS Node.js 20+ 호스팅/VPS에 이 폴더 배포
2. `npm install` 실행, `npm run keys`로 VAPID 공개/비밀키 생성
3. 서버 환경변수 설정:
   - `VAPID_PUBLIC_KEY`: 생성한 공개키
   - `VAPID_PRIVATE_KEY`: 생성한 비밀키 (**GitHub에 올리지 않기**)
   - `VAPID_SUBJECT`: `mailto:you@example.com` 형식
   - `PUSH_REGISTER_TOKEN`: 임의의 긴 비밀번호 (**GitHub에 올리지 않기**)
   - `APP_ORIGIN`: `https://jkh2311.github.io` (기본값)
   - `PORT`: 호스팅 포트 (기본 8787)
   - `SUBSCRIPTIONS_FILE`: 구독을 보관할 영속 파일 경로
4. `npm start`. 호스팅에서 HTTPS URL을 제공해야 합니다. 재시작 시에도 구독 파일 유지 필요.
5. 앱 설정 > LONG/SHORT 알림의 '원격 푸시'에 HTTPS 서버 URL과 등록 코드 입력
6. '원격 푸시 연결' → '원격 푸시 테스트'를 눌러 잠금 화면 수신 확인

서버는 바이낸스 공개 1분봉 REST를 약 2.5초마다 확인하고 확정 RMI 신호를 Web Push로 전송합니다.
Apple 푸시·네트워크 지연 및 거래소 API 지연 때문에 0초 즉시 도착은 보장하지 않습니다.
웹앱 1분봉 신호에서 사용하는 횡보/하락/상승 전략을 재구현하며, 등록 시 선택한 설정값을 서버에 전달합니다.
전략 또는 신호 임계값을 바꾸면 다시 '원격 푸시 연결'을 눌러 서버에 반영해야 합니다.
서버가 기동된 뒤 처음 확인하는 봉은 중복/과거 알림 방지를 위해 건너뜁니다.

**보안:** Binance API 키/거래 계정 정보는 전혀 요구하지 않습니다. 알림에 필요한 푸시 구독과 RMI 설정만 별도 서버로 보냅니다.
HTTPS와 강력한 등록 코드, 호스팅의 영속 저장을 사용하세요. 등록 코드가 유출되면 변경하세요.
비활성화는 서버에서 구독을 삭제하거나 서버를 정지해야 합니다. 앱 안의 '로컬 알림 OFF'는 서버 구독 취소를 의미하지 않습니다.
